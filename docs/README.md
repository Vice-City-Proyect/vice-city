# Documentación Frontend - Vice City Iguana Club

## Archivos generados

| Archivo | Propósito |
|---|---|
| `DESIGN-SYSTEM.md` | Sistema de diseño de la landing: tokens, tipografía, botones, cards, secciones, responsive y convenciones visuales |
| `FRONTEND-GUIDE.md` | Guía completa: arquitectura, componentes, datos, patrones |
| `FRONTEND-QUICKSTART.md` | Guía rápida para desarrollo y agregar código |
| `FRONTEND-MAP.md` | Mapa visual del árbol de componentes y flujo |
| `COMPONENTS-API.md` | Referencia rápida de props/APIs de componentes |

## Recomendación
Leer `DESIGN-SYSTEM.md` primero para entender qué diseño usamos y cómo mantenerlo consistente,
luego `FRONTEND-GUIDE.md` para entender el proyecto, y usar los demás como referencia.
